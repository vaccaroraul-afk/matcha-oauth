Inicio Política de privacidad Condiciones del servicio

Esta política describe cómo el cliente OAuth “Matcha” trata los datos de Google. Lo usa únicamente su dueño, Raúl Vaccaro, con su propia cuenta de Gmail.

Datos a los que accede

Con el permiso https://mail.google.com/, el programa de correo matcha accede por IMAP y SMTP a la cuenta de Gmail autorizada: lee los mensajes y carpetas, y envía los correos que el dueño escribe.

Dónde se guardan

  • Los mensajes que matcha descarga se guardan en una caché local, en el computador del dueño.
  • Los tokens de OAuth se guardan en archivos locales que solo puede leer el usuario del sistema.
  • No existe ningún servidor propio: los datos viajan solo entre el computador del dueño y Google.

Con quién se comparten

Con nadie. Los datos de Google no se venden, no se transfieren a terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial.

Uso limitado

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions, o con el comando matcha oauth revoke. Al revocarlo, matcha deja de poder acceder a la cuenta; la caché local se puede borrar eliminando la carpeta de caché de matcha.

Cambios

Si esta política cambia, se publicará aquí con una nueva fecha de vigencia.

Privacy policy (English)

“Matcha” is a personal Google OAuth client used only by its owner, Raúl Vaccaro, with his own Gmail account. Using the https://mail.google.com/ scope, the open-source mail client matcha reads and sends mail over IMAP and SMTP. Downloaded messages are cached locally and OAuth tokens are stored in local files readable only by the owner's system user. There is no server: data travels only between the owner's computer and Google. Google user data is not sold, not transferred to third parties, not used for advertising and not used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
