# matcha-oauth

Páginas públicas (inicio, política de privacidad y condiciones del servicio) del
cliente OAuth personal de Google "Matcha", que usa el cliente de correo de terminal
[matcha](https://github.com/floatpane/matcha) para acceder a Gmail.

Publicadas con GitHub Pages en https://vaccaroraul-afk.github.io/matcha-oauth/
